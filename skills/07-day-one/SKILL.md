# 07 · Day one in five lines

**Goal.** The team's day in five true lines, so tomorrow starts where today ended.

Work in the team's product folder: the current folder, or the folder below it that has `product.md`. If there is none, run `/ai-product:ai-product-setup` first. Remind the team they can add files to `documents/` at any time, and read any new ones.

## Steps

1. Read every mission file so far, `panel/` and `handoff/`.
2. Fill `templates/07-day-one.md` into `07-day-one.md`: one line each for the ideal customer, the top problem so far with its evidence, the best real customer quote, what the AI got wrong today, and the question to start tomorrow with. Each line names the file it comes from.
3. Ask the team to edit until every line is true. Apply their edits.

## Done when

Two people on the team can read it out without anyone objecting.

Finish with: "Tomorrow starts with `/ai-product:08-make-the-case`."
