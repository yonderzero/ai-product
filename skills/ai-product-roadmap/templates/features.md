## The features, prioritised

| # | Feature | Kind | Flow | Value | Pay | Confidence | Effort | Priority | Horizon |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | agent capability / control / visibility / data | | 1–5 | 1–5 | Strong / Good / Thin / Assumption | 1–5 | | Now / Next / Later |

- **Value:** the hours it gives back and how much customers want it (real customers, then the panel).
- **Pay:** how likely customers pay for it.
- **Confidence:** the evidence grade (Strong 5, Good 4, Thin 2, Assumption 1).
- **Effort:** 1 small, on data we already hold … 5 needs data or rights we don't have. Agreed with the product manager, and with developers where possible.
- **Priority** = (value + pay) × confidence points ÷ (effort + 1). Show the working.
